01

정보보안 3요소

보안

모든 보안의 출발점. 두문자 기·무·가로 외우고, 단답으로 자주 나옵니다.

CIA

기밀성 · 무결성 · 가용성

★★★
기밀성Confidentiality — 인가된 사용자만 정보에 접근 가능 (노출 방지)
무결성Integrity — 인가된 사용자만 정보를 수정 가능 (변조 방지)
가용성Availability — 인가된 사용자가 필요할 때 언제든 접근 가능
🔑 기·무·가 (기밀성·무결성·가용성). 추가로 부인방지(Non-repudiation), 인증(Authentication)도 함께 외우면 좋습니다.
02

암호화 — 대칭 vs 비대칭

보안

거의 매회 출제. 키 개수와 알고리즘 이름을 짝지어 외우는 게 핵심입니다.

CRYPTO

대칭키 vs 비대칭키

★★★
대칭키암호화·복호화에 같은 키 사용. 빠르지만 키 분배 어려움.
예: DES, AES(키 128/192/256비트), SEED·ARIA(국산 블록암호, 기본 128비트), RC4(스트림)
비대칭키공개키로 암호화, 개인키로 복호화 (키 2개). 느리지만 키 분배 쉬움.
암·복호화 예: RSA, ECC  |  키 교환(키 분배): 디피-헬만(Diffie-Hellman) — 공개키 기반 키 교환 알고리즘(암·복호화 알고리즘이 아님)
해시단방향 암호화 (복호화 불가). 무결성 검증용.
예: SHA, MD5, HAS-160
⚠ 핵심 함정: 비대칭키는 공개키로 암호화 → 개인키로 복호화가 기본(기밀성). 반대로 개인키로 서명 → 공개키로 검증은 전자서명(부인방지). 방향을 정확히.
🔑 대칭 = 다·에·시·아(DES·AES·SEED·ARIA) / 비대칭 = RSA·ECC / 해시 = SHA·MD5.
03

공격기법 — 웹 취약점

보안

약술 최대 빈출. 각 공격의 핵심 동작 한 문장을 정확히 쓸 수 있어야 합니다.

ATTACK

주요 웹 공격기법

★★★
SQL 인젝션입력값에 악의적 SQL을 삽입해 DB를 비정상 조회·조작하는 공격. (방어: Prepared Statement)
XSS웹 페이지에 악성 스크립트를 삽입해 쿠키·세션 등 개인정보를 탈취. (Cross-Site Scripting)
CSRF사용자가 자신도 모르게 공격자가 의도한 요청을 보내게 하는 공격. (Cross-Site Request Forgery)
명령어 삽입검증 안 된 입력값이 OS 명령어로 실행되도록 하는 공격 (Command Injection)
⚠ XSS vs CSRF 구분: XSS는 스크립트 실행으로 정보 탈취, CSRF는 위조된 요청으로 행위 유발. 둘 다 빈출이니 차이를 명확히.
DOS

서비스 거부 · 네트워크 공격

★★☆
DoS대량 트래픽으로 시스템을 마비시켜 정상 서비스를 방해
DDoS여러 좀비 PC를 동원한 분산 서비스 거부 공격
스니핑네트워크 패킷을 몰래 가로채 정보를 훔쳐봄 (수동적)
스푸핑IP·MAC 등을 위조해 신뢰된 대상으로 가장 (능동적)
💡 스니핑 vs 스푸핑: 스니핑은 "엿보기"(가로채기), 스푸핑은 "위장"(속이기). 헷갈리기 쉬우니 동사로 구분.
04

접근통제 · 인증

보안

접근통제 모델 3종과 인증 방식이 단답으로 출제됩니다.

AC

접근통제 모델 (DAC/MAC/RBAC)

★★☆
DAC임의적 접근통제 — 자원 소유자가 권한 부여 (Discretionary)
MAC강제적 접근통제 — 보안 등급에 따라 시스템이 강제 (Mandatory)
RBAC역할 기반 접근통제 — 역할(직책)에 따라 권한 부여 (Role-Based)
🔐 인증 방식: SSO=한 번 인증으로 여러 시스템 접근 / OTP=일회용 비밀번호 / 커버로스(Kerberos)=티켓 기반 인증.
SIGN

전자서명 · PKI

★★☆
전자서명개인키로 서명 → 공개키로 검증. 인증·무결성·부인방지를 보장 (기밀성은 보장하지 않음).
PKI공개키 기반구조(Public Key Infrastructure). 공개키·인증서를 신뢰성 있게 관리하는 체계.
CA인증기관(Certificate Authority). 공개키의 소유자를 보증하는 인증서를 발급·관리.
⚠ 함정: 전자서명은 기밀성을 제공하지 않습니다. 기밀성(암호화)은 수신자의 공개키로 별도 암호화해야 보장됩니다.
05

보안 솔루션

보안

방화벽·IDS·IPS·VPN은 약어와 핵심 역할을 정확히 매칭해야 합니다. 특히 IDS vs IPS, AH vs ESP가 빈출.

FW/IDS

방화벽 · IDS · IPS

★★★
방화벽내·외부 네트워크 사이에서 정책에 따라 패킷을 허용/차단. 발전 순서: 패킷 필터링 → 스테이트풀(상태 추적) → 애플리케이션 게이트웨이(프록시)
IDS침입 탐지 시스템(Intrusion Detection System). 비정상 행위를 탐지·경고만 함 (오용 탐지 / 이상 탐지)
IPS침입 방지 시스템(Intrusion Prevention System). 탐지 + 능동적 차단까지 수행
💡 IDS vs IPS: IDS=탐지만(수동), IPS=탐지+차단(능동). 방화벽은 정책 기반 허용/차단이 핵심.
VPN

VPN · IPSec

★★☆
VPN가상사설망(Virtual Private Network). 공중망에 암호화된 터널을 만들어 사설망처럼 안전하게 통신
AHIPSec의 인증 헤더(Authentication Header). 무결성·인증 제공 (기밀성 X)
ESPIPSec의 보안 페이로드(Encapsulating Security Payload). 기밀성 + 무결성·인증 제공
동작 모드전송 모드=페이로드만 보호(종단 간) / 터널 모드=IP 헤더 포함 전체 보호(게이트웨이 간)
⚠ AH vs ESP: AH는 기밀성을 제공하지 않습니다(암호화 X). 기밀성이 필요하면 ESP를 사용.
06

추가 공격기법

보안

최근 빈출 공격기법. 단답·약술로 자주 나오니 핵심 동작 한 문장으로 기억하세요.

ATTACK+

지능형·사회공학 공격

★★☆
APT지능형 지속 위협(Advanced Persistent Threat). 특정 대상을 장기간 은밀히 공격
랜섬웨어파일을 암호화한 뒤 복호화 대가로 금전을 요구하는 악성코드 (Ransomware)
피싱/스미싱피싱=가짜 사이트·메일로 정보 탈취 / 스미싱=문자(SMS)로 악성 링크 유도
제로데이제로데이(0-day) — 보안 패치가 나오기 전 취약점을 악용하는 공격
무차별 대입Brute Force — 모든 경우의 수를 대입해 비밀번호를 알아냄. 사전 공격은 사전 단어를 대입
사회공학Social Engineering — 사람의 심리·신뢰를 이용해 정보를 빼냄 (기술적 취약점 X)
💡 구분: 무차별 대입=모든 조합, 사전 공격=사전 단어 목록. 스미싱의 "S"는 SMS(문자)를 의미.
07

네트워크 — 프로토콜

네트워크

계층별 프로토콜과 역할을 매칭하는 문제가 단골. 약어와 풀네임을 함께 외우세요.

PROTO

주요 프로토콜

★★★
TCP연결형, 신뢰성 보장, 순서 보장 (3-way handshake)
UDP비연결형, 빠르지만 신뢰성 없음 (실시간 스트리밍)
HTTP/HTTPS웹 통신 프로토콜 / HTTPS는 SSL·TLS로 암호화
FTP파일 전송 프로토콜
SMTP/POP3메일 전송(SMTP) / 메일 수신(POP3, IMAP)
ARPIP 주소 → MAC 주소 변환 (RARP는 반대)
ICMP오류·제어 메시지 전송 (ping이 사용)
SNMP네트워크 장비 관리·모니터링
⚠ TCP vs UDP: TCP=신뢰성(연결형), UDP=속도(비연결형). 가장 자주 나오는 비교 문제입니다.
PORT

well-known 포트 · TCP 연결

★★☆
주요 포트HTTP 80 · HTTPS 443 · FTP 20(데이터)/21(제어) · SMTP 25 · POP3 110 · DNS 53
3-wayTCP 연결 설정: SYN → SYN/ACK → ACK (3단계 핸드셰이크)
4-wayTCP 연결 해제: FIN → ACK → FIN → ACK (4단계 핸드셰이크)
🔑 연결=3-way(SYN·SYN/ACK·ACK), 해제=4-way(FIN·ACK·FIN·ACK). 포트는 숫자와 서비스를 짝지어 암기.
TCP/IP

TCP/IP 4계층 ↔ OSI 7계층 대응

★★☆
응용Application — OSI 5~7계층(세션·표현·응용) 대응. HTTP, FTP, SMTP, DNS
전송Transport — OSI 4계층 대응. TCP, UDP
인터넷Internet — OSI 3계층 대응. IP, ICMP, ARP, IGMP
네트워크
액세스Network Access — OSI 1~2계층(물리·데이터링크) 대응. Ethernet
🌐 TCP/IP 4계층: 응용 / 전송 / 인터넷 / 네트워크액세스. 실제 인터넷의 표준 모델로, OSI 7계층을 통합한 형태입니다.
08

네트워크 — 주소 · 라우팅

네트워크

IPv4/IPv6 차이, 라우팅 프로토콜, 네트워크 장비가 출제 포인트.

ADDR

IP 주소와 라우팅

★★☆
IPv432비트 주소 (8비트씩 4개), 약 43억 개
IPv6128비트 주소 (16비트씩 8그룹, 콜론(:)으로 구분, 각 그룹 16진수 4자리), IPv4 주소 고갈 해결
라우팅목적지까지 최적 경로를 찾아 패킷 전달
RIP/OSPFRIP=거리벡터(홉 수) / OSPF=링크상태(최단경로)
🌐 네트워크 장비: 라우터(경로 결정, 3계층) / 스위치(2계층) / 허브(1계층) / 게이트웨이(프로토콜 변환).
🌐

OSI 7계층 인터랙티브

필기·실기 단골입니다. 각 계층을 눌러 역할·데이터 단위·프로토콜을 확인하세요. 순서와 계층별 프로토콜이 핵심.

🔑 두문자 (아래→위): 물·데·네·전·세·표·응 — "물 데 네(가) 전세 표(를) 응(원)" 같은 식으로 본인만의 문장을 만들어 외우세요.

7계층 구조 (위 = 사용자, 아래 = 하드웨어)

계층을 탭하세요 ↓
상위 — 사용자 지원 계층
