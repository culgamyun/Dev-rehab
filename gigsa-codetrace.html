01

C — 포인터 기본

C

실기 C의 핵심이자 최대 함정. 주소(&)와 값(*)의 관계만 정확하면 대부분 풀립니다.

PTR

포인터 & 와 *

★★★
  • &a — 변수 a의 주소 (번지 연산자)
  • *p — 포인터 p가 가리키는 곳의 값 (역참조)
  • int *p = &a; — p에 a의 주소 저장 → *p는 곧 a
●●●pointer.c
int a = 50;
int *b = &a;     // b = a의 주소
*b = *b + 20;   // b가 가리키는 a의 값 += 20
printf("%d", a);  // a도 함께 바뀜 → 70
🎯 핵심: 포인터로 값을 바꾸면 원본 변수도 바뀝니다. *b를 통한 수정 = a를 직접 수정.
STR

문자열 포인터 + 산술

★★★

char *p = "KOREA"; 일 때 출력 패턴이 단골입니다.

  • %s, p → 그 주소부터 문자열 전체: KOREA
  • %s, p+1 → 다음 글자부터: OREA
  • %c, *p → 첫 글자 한 개: K
  • %c, *(p+3) → 4번째 글자: E
  • %c, *p+4 → 'K'(75)+4=79: O
⚠ 최대 함정: *(p+3) 와 *p+3 는 완전히 다릅니다. 전자는 4번째 문자, 후자는 첫 문자 아스키 +3. 괄호 위치를 반드시 확인.
02

C — 배열 · 2차원 포인터

C

2차원 배열 포인터는 가장 어려운 유형. 행을 넘긴다는 개념이 핵심입니다.

ARR

2차원 배열과 (*p)[n]

★★☆
●●●array2d.c
int arr[2][3] = {{1,2,3},{4,5,6}};
int (*p)[3] = arr;   // 3열짜리 행 포인터
printf("%d", *(*(p+1)+2));  // arr[1][2] → 6
printf("%d", p[0][1]);       // arr[0][1] → 2
  • (p+1) — 1칸이 아니라 한 행을 넘김
  • *(p+1) — 1행의 시작 주소
  • *(*(p+1)+2) — 1행 2열의 값 = arr[1][2]
💡 *(*(p+i)+j) = p[i][j] = arr[i][j]. 세 표기가 모두 같은 값입니다.
03

C — 재귀 · 변수 스코프

C

재귀는 호출 스택을 거꾸로 펼치면 풀리고, 스코프는 블록 단위 변수 가림이 함정.

REC

재귀호출 (팩토리얼)

★★★
●●●factorial.c
int f(int n){
  if(n <= 1) return 1;
  else return n * f(n-1);
}
// f(5) = 5*4*3*2*1 = 120
🎯 푸는 법: 끝(n=1)까지 펼친 뒤 거꾸로 곱하기. f(5)→5×f(4)→5×4×f(3)→…→5×4×3×2×1=120.
SCOPE

변수 스코프 (블록 가림)

★★☆

안쪽 블록 { }에서 같은 이름으로 다시 선언하면, 그 블록 안에서만 새 변수가 우선합니다.

⚠ 주의: 안쪽 블록에서 선언한 변수는 블록을 벗어나면 사라지고, 바깥 변수 값은 그대로 유지됩니다. "어느 블록의 변수인가"를 추적하세요.
LOOP

do-while · 중첩 루프와 break

★★☆

do-while은 본문을 먼저 실행하고 조건을 나중에 검사하므로, 조건이 처음부터 거짓이어도 본문이 최소 1회 실행됩니다.

●●●loop.c
int i = 10;
do {
  printf("%d ", i);  // 조건이 거짓이어도 1회 실행 → 10
} while(i < 5);     // 10<5 거짓 → 종료

for(int a=0; a<2; a++)
  for(int b=0; b<3; b++){
    if(b == 1) break;  // 안쪽 루프만 탈출, 바깥은 계속
    printf("%d%d ", a, b);  // 00 10
  }
⚠ 핵심: 중첩 루프에서 break는 자신이 속한 안쪽 루프만 빠져나가고 바깥 루프는 계속 돕니다. while/for는 조건을 먼저 검사해 0회 실행이 가능하지만, do-while은 무조건 1회는 실행합니다.
04

C — 구조체 · 구조체 포인터

C

거의 매회 출제되는 핵심. 점(.)과 화살표(->) 접근 구분, 구조체 배열+포인터 연산이 단골입니다.

STRUCT

구조체 접근 — . 과 ->

★★★
  • 구조체변수.멤버 — 일반 변수는 점(.)으로 접근
  • 포인터->멤버 — 구조체 포인터는 화살표(->)로 접근
  • (*포인터).멤버 — 화살표와 동일한 표현
●●●struct.c
struct Point { int x, y; };
struct Point p = {3, 7};
struct Point *pp = &p;
printf("%d", p.x);    // 점 접근 → 3
printf("%d", pp->y);  // 화살표 접근 → 7
pp->x = pp->x + pp->y;     // 3+7=10, 원본 p.x도 10
⚠ 최대 함정: 변수는 ., 포인터는 ->. 섞어 쓰면 틀립니다. 포인터로 멤버를 바꾸면 원본 구조체도 바뀝니다.
STRUCT

구조체 배열 + 포인터 연산

★★★

구조체 배열을 포인터로 가리키고 (p+n)->멤버로 접근하는 기출 단골 패턴입니다.

●●●struct_arr.c
struct jsu { char name[12]; int os, db; };
struct jsu st[3] = {{"d1",95,88},
                  {"d2",84,91},{"d3",86,75}};
struct jsu *p = &st[0];
// (p+1) = st[1], (p+2) = st[2]
printf("%d", (p+1)->os + (p+2)->db);  // 84+75=159
💡 (p+1)는 배열의 다음 구조체(st[1]). 포인터이므로 멤버 접근은 ->. (p+1)->os = st[1].os.
05

Java — 상속 · 오버라이딩

JAVA

Java의 핵심. 부모 타입 변수가 자식 객체를 가리킬 때 어느 메서드가 실행되는가가 단골.

OOP

오버라이딩과 동적 바인딩

★★★
●●●Override.java
class Animal {
  String sound(){ return "..."; }
}
class Dog extends Animal {
  String sound(){ return "Woof"; }
}
Animal a = new Dog();
println(a.sound());   // Woof (실제 객체 기준)
🎯 핵심 규칙: 변수의 타입이 아니라 실제 생성된 객체의 메서드가 실행됩니다(동적 바인딩). Animal a = new Dog() → Dog의 sound().
STR

문자열 + 정수 연산

★★☆
  • "결과" + 5 + 3 → 왼→오: "결과5" + 3 = 결과53
  • "결과" + (5 + 3) → 괄호 먼저: 결과8
  • 5 + 3 + "점" → 왼→오: 8 + "점" = 8점
⚠ 함정: 문자열과 + 연산은 왼쪽부터 순서대로. 문자열을 만난 뒤부터는 모두 이어붙이기(concatenation)가 됩니다.
TYPE

정수 나눗셈 · 형변환 (char 승격)

★★☆

정수끼리 나누면 소수점이 버려지고, 한쪽이 실수면 실수 연산이 됩니다. char는 산술 연산 시 int로 승격됩니다.

  • 7 / 2 → 정수끼리라 소수점 버림(정수 절단): 3
  • 7.0 / 2 → 한쪽이 실수라 실수 나눗셈: 3.5
  • (char)('A' + 1) → 66을 char로 캐스팅: B
  • 'A' + 1 → char가 int로 승격되어: 66
⚠ 함정: 'A'+1은 그냥 출력하면 정수 66이고, (char)로 다시 캐스팅해야 문자 B가 됩니다. 정수 나눗셈은 7/2=3처럼 몫만 남습니다.
STR

String 비교 — == 와 equals()

★★★

2023년 2회 등 단골. ==는 참조(주소) 비교, equals()는 내용 비교입니다. 리터럴 문자열은 String 풀(pool)을 공유하지만 new String()은 매번 별도 객체입니다.

●●●StringPool.java
String a = "P";
String b = "P";             // 리터럴 → 풀 공유
String c = new String("P"); // new → 별도 객체
print(a == b);        // true (같은 풀 객체)
print(a == c);        // false (주소 다름)
print(a.equals(c));   // true (내용은 같음)
⚠ 최대 함정: 문자열 내용 비교는 반드시 equals()를 쓰세요. ==는 주소가 같은지만 보므로, new String()으로 만든 객체와는 항상 false입니다.
CTOR

생성자 호출 순서 (super + 오버라이딩)

★★☆

자식 객체 생성 시 부모 생성자가 먼저 실행됩니다. 이때 호출되는 메서드는 오버라이딩된 자식 것입니다.

●●●ctor.java
class A {
  A(){ print("A"); func(); }   // func는 오버라이딩됨
  void func(){ print("B"); }
}
class B extends A {
  B(){ super(); print("D"); }
  void func(){ print("E"); }
}
new B();   // 출력: AED
🎯 추적: B() → super()로 A() 실행 → "A" 출력 → func() 호출하는데 실제 객체가 B라 E 실행 → A() 끝 → B()의 "D". 결과 AED.
06

Java — switch · 비트연산

JAVA

두 가지 모두 빈출 함정. switch의 break 누락과 비트 연산자는 거의 매회 등장합니다.

SWITCH

switch fall-through (break 누락)

★★★

break가 없으면 일치한 case부터 아래 case들과 default까지 줄줄이 실행됩니다(fall through).

●●●switch.java
int i = 3, k = 1;
switch(i){
  case 3: k = 0;       // 여기 진입, break 없음
  case 4: k += 3;      // k=3
  case 5: k -= 10;     // k=-7
  default: k--;        // k=-8
}
print(k);   // -8
⚠ 핵심: case마다 break가 있는지 확인하세요. 없으면 아래로 계속 실행됩니다. i=3 → 0 → +3=3 → -10=-7 → --=-8.
BIT

비트 연산자 & | ^ << >>

★★★

2진수로 바꿔서 자리별로 계산. a=5(101), b=3(011) 기준.

  • a & b (AND, 둘 다 1) → 101 & 011 = 001 = 1
  • a | b (OR, 하나라도 1) → 111 = 7
  • a ^ b (XOR, 다르면 1) → 110 = 6
  • a << 1 (왼쪽 시프트, ×2) → 1010 = 10
  • a >> 1 (오른쪽 시프트, ÷2) → 10 = 2
💡 시프트 암기: <<n = ×2ⁿ, >>n = ÷2ⁿ. XOR(^)는 "같으면 0, 다르면 1"이 핵심.
07

Java — 배열 · 기본값

JAVA

배열 기본값, 메서드의 배열 반환이 출제 포인트.

ARR

배열 기본값과 반환

★★☆
  • int[] arr = new int[4]; — 기본값 모두 0
  • 객체 배열의 기본값은 null
  • arr.length — 배열 크기 (괄호 없음, 메서드 아님)
●●●array.java
int[] make(){
  int[] t = new int[4];
  for(int i=0; i<t.length; i++) t[i] = i*2;
  return t;   // {0, 2, 4, 6} → 합 12
}
💡 String.length()는 메서드(괄호 O), 배열.length는 필드(괄호 X). 헷갈리지 마세요.

Python — 슬라이싱

PYTHON

최근 출제 비중이 늘었습니다. [start:end:step] 규칙, 특히 end 미포함과 음수 step이 핵심.

SLICE

슬라이싱 [start:end:step]

★★★

s = "PYTHON" 기준 (인덱스 0~5)

  • s[1:4] → 1,2,3번 (end=4 미포함): YTH
  • s[:3] → 처음부터 2번까지: PYT
  • s[::-1] → 역순(step=-1): NOHTYP
  • s[::2] → 2칸씩(0,2,4): PTO
  • s[4:1:-1] → 4→2번 역방향(1 미포함): OHT
  • s[1:4:-1] → 진행 방향과 어긋남: 빈 문자열
⚠ 핵심 함정: end는 포함하지 않습니다. s[1:4]는 1~3번까지(3개). [::-1]은 문자열 뒤집기 단골.
💡 음수 step 보조설명: step이 음수면 진행 방향이 오른쪽→왼쪽이라 start > end여야 결과가 나옵니다. 'PYTHON'[4:1:-1]=OHT(4→2), 반대로 'PYTHON'[1:4:-1]은 방향이 안 맞아 ''(빈 문자열)입니다.
LIST

리스트 · 딕셔너리

★★☆
  • a[1:3] = [20,30,40] — 슬라이스 자리에 통째 교체 (길이 달라도 됨)
  • 리스트 메서드 — append(끝 추가), pop(꺼내기), len(개수)
  • 딕셔너리 — d['키']=값, d.values(), d.keys(), d.items()
  • 리스트 컴프리헨션 — [x*x for x in range(1,4)] = [1, 4, 9]
💡 "ab" * 3 = ababab (문자열 반복), [0]*3 = [0, 0, 0] (리스트 반복).
🎯 리스트 컴프리헨션: [식 for 변수 in 반복대상] 형태로 한 줄에 리스트를 생성합니다. range(1,4)는 1,2,3이므로 각각 제곱해 [1, 4, 9].
OP

연산자 + lambda/map

★★☆
  • // — 몫(정수나눗셈): 7//2 = 3
  • % — 나머지: 7%2 = 1
  • ** — 거듭제곱: 2**10 = 1024
  • map(lambda x: x*x, [1,2,3]) → [1, 4, 9]
🎯 list(map(함수, 리스트)) = 각 원소에 함수 적용. lambda는 이름 없는 즉석 함수.
▶
