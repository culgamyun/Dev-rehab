🤖 로보틱스 입문 — Python 중심 커리큘럼

기초 수학·좌표계부터 센서·제어·ROS 2·인식·SLAM까지 한 챕터씩. R1부터 차례로 공개됩니다. (도면/블루프린트 스타일 일러스트)

수학 리부트 (선수지식)

수학을 오래 놓았어도 OK. 수·식·함수부터 각도·삼각함수·벡터·행렬·미분·적분·정규분포까지, 증명 없이 그림·코드로 다지는 로보틱스 선수지식 참고서.

진척도: 시작 전 Python · numpy · matplotlib
R1

로보틱스 입문 & 선형대수 기초

로봇 3요소(센서·액추에이터·제어기), 좌표계와 강체 변환, numpy 벡터·행렬 연산, 회전행렬 SO(2)/SO(3)과 동차변환행렬 SE(3)로 점을 변환하는 기초를 다집니다.

진척도: 시작 전 Python · numpy
R2

센서와 신호

IMU·엔코더·LiDAR·초음파·카메라의 측정 원리, 샘플링과 나이퀴스트, 가우시안 노이즈, 그리고 이동평균·1D 칼만 필터로 노이즈를 걸러 깨끗한 값을 얻는 법.

진척도: 시작 전 Python · numpy · matplotlib
R3

액추에이터 & 임베디드

DC·서보·스텝 모터, PWM 듀티로 속도 조절, 서보 펄스폭으로 각도 제어, GPIO·I2C·SPI·UART와 실시간성. 모터 제어 수학은 실행 검증, 하드웨어는 gpiozero 패턴.

진척도: 시작 전 Python · gpiozero
R4

키네매틱스 (기구학)

2링크 로봇팔의 정/역기구학(FK·IK, 두 해), DH 파라미터, 자코비안·특이점, 차동구동 모바일 로봇 오도메트리까지 — numpy로 직접 풀고 FK→IK 왕복 검증.

진척도: 시작 전 Python · numpy · matplotlib
R5

제어 이론 (PID)

개/폐루프 피드백, PID 세 항(비례·적분·미분)의 역할, 게인 튜닝과 지글러-니콜스, 상태공간 개념 — P/PI/PID 추종 시뮬레이션으로 잔류오차·오버슈트를 눈으로 확인.

진척도: 시작 전 Python · numpy · matplotlib
R6

ROS 2 기초

로봇 소프트웨어 미들웨어 ROS 2 — 노드·토픽(pub/sub)·서비스·액션, rclpy 발행자/구독자 노드 패턴, 패키지·colcon·런치. 토픽 개념은 순수 파이썬으로 실행 검증.

진척도: 시작 전 Python · rclpy (ROS 2)
R7

ROS 2 심화 & 시뮬레이션

TF2 좌표 프레임 트리(R1 SE(3) 자동 변환), URDF 로봇 모델(link·joint), 물리 시뮬레이터 Gazebo와 시각화 도구 RViz의 차이. TF 변환 트리는 numpy로 실행 검증.

진척도: 시작 전 ROS 2 · TF2 · URDF · numpy
R8

인식 (Perception · OpenCV)

진척도: 시작 전 Python · OpenCV
R9

위치추정 · SLAM · 내비게이션

오도메트리+센서를 융합하는 칼만/파티클 필터, SLAM(닭-달걀·루프클로저), A*/Dijkstra/RRT 경로계획, Nav2 개요. A* 경로계획·1D 칼만을 numpy로 실행 검증.

진척도: 시작 전 Python · numpy · A* · 칼만
R10 🎉

매니퓰레이션 & 학습기반 제어

🚀 실행 방법

읽기만 할지, 실제로 돌려보며 만들지 두 갈래가 있습니다. Docker는 안 써도 됩니다.

📖 1. 지금 이 학습 사이트 보기

글·다이어그램·퀴즈는 index.html 더블클릭만으로 OK. 검색(Ctrl+K)·용어 hover 툴팁·데모샵까지 쓰려면 로컬 서버가 필요합니다(파일 직접 열기는 브라우저 CORS로 막힘).

python -m http.server 5500

→ 브라우저에서 http://localhost:5500 접속. (또는 VS Code Live Server 확장 → index.html 우클릭 → "Open with Live Server")

🛠️ 2. 실습 레포 실행 — Docker 없이 (권장)

antigravity-app/에서 빌드 체크포인트를 직접 구현합니다. PostgreSQL·Redis·Docker 전부 불필요(H2 인메모리).

백엔드 (Spring Boot · H2)

cd antigravity-app/backend && ./gradlew bootRun --args="--spring.profiles.active=dev"

→ http://localhost:8080/api/products (시드 상품) · /swagger-ui.html (API 문서)
※ 최초 1회만 gradle wrapper로 gradlew 생성, 또는 IntelliJ로 열면 자동

프론트엔드 (Next.js)

cd antigravity-app/frontend && npm install && npm run dev

→ http://localhost:3000

🐳 3. (선택) Docker 풀스택 — Ch8 학습 때만

Ch8(데브옵스)에서 컨테이너·CI를 배울 때만 사용. 평소엔 위 2번으로 충분합니다.

cd antigravity-app && docker compose up --build
