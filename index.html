🚀 실행 방법

읽기만 할지, 실제로 돌려보며 만들지 두 갈래가 있습니다. Docker는 안 써도 됩니다.

📖 1. 지금 이 학습 사이트 보기

글·다이어그램·퀴즈는 index.html 더블클릭만으로 OK. 검색(Ctrl+K)·용어 hover 툴팁·데모샵까지 쓰려면 로컬 서버가 필요합니다(파일 직접 열기는 브라우저 CORS로 막힘).

python -m http.server 5500

→ 브라우저에서 http://localhost:5500 접속. (또는 VS Code Live Server 확장 → index.html 우클릭 → "Open with Live Server")

🛠️ 2. 실습 레포 실행 — Docker 없이 (권장)

antigravity-app/에서 빌드 체크포인트를 직접 구현합니다. PostgreSQL·Redis·Docker 전부 불필요(H2 인메모리).

백엔드 (Spring Boot · H2)

cd antigravity-app/backend && ./gradlew bootRun --args="--spring.profiles.active=dev"

→ http://localhost:8080/api/products (시드 상품) · /swagger-ui.html (API 문서)
※ 최초 1회만 gradle wrapper로 gradlew 생성, 또는 IntelliJ로 열면 자동

프론트엔드 (Next.js)

cd antigravity-app/frontend && npm install && npm run dev

→ http://localhost:3000

🐳 3. (선택) Docker 풀스택 — Ch8 학습 때만

Ch8(데브옵스)에서 컨테이너·CI를 배울 때만 사용. 평소엔 위 2번으로 충분합니다.

cd antigravity-app && docker compose up --build
